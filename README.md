# TB Race Results

Race results and championship standings for the WJF Trophy GT3 Endurance Championship, Season 18.

- `index.html` – race results, one tab per round
- `championship.html` – driver standings
- `data/season18.js` – all results and standings data
- `assets/` – styling and page logic

This example was transcribed from the club's result images. A later version will build `data/` automatically from uploaded CSV exports.
